1. TITLE
Vortex Torrent

2. SHORT DESCRIPTION
A fast, free desktop BitTorrent downloader for Windows. Add .torrent files or magnet links, manage multiple downloads, and control speeds - all in one clean app.

3. LONG DESCRIPTION
Vortex Torrent is a full-featured BitTorrent client for Windows built on the battle-tested libtorrent engine. It makes downloading legal, open content simple and fast. Add .torrent files or paste magnet links and Vortex handles the rest - discovering peers through DHT, peer exchange, and trackers so you get the fastest available speeds.

Manage multiple downloads at once with a live table showing progress, download and upload speed, seed/peer counts, and estimated time remaining. Pause, resume, or remove torrents individually, or delete files completely when a download is no longer needed. Speed limits and the listening port are configurable from a single settings dialog.

Built with your privacy and control in mind, Vortex Torrent stores all configuration locally and includes a built-in updater that checks GitHub for new releases, so you always run the latest version. Everything is open source and free.
