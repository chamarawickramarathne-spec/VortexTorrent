2. SHORT DESCRIPTION

3. LONG DESCRIPTION
Vortex Torrent is a full-featured BitTorrent client for Windows built on the battle-tested libtorrent engine, wrapped in a sleek modern dark interface. It makes downloading legal, open content simple and fast. Add .torrent files or paste magnet links and Vortex handles the rest - discovering peers through DHT, peer exchange, and trackers so you get the fastest available speeds.

A beautiful, dark-themed interface shows every download as a live card with a progress bar, download and upload speed, seed and peer counts, and estimated time remaining. Pause, resume, or remove torrents from the toolbar, a right-click menu, or handy keyboard shortcuts (Ctrl+O, Ctrl+M, Space, Delete). Double-click a finished download to open its folder instantly. Set your own download folder, speed limits, and listening port from a single settings dialog.

Built with your privacy and control in mind, Vortex Torrent stores all configuration locally and includes a built-in updater that checks GitHub for new releases, so you always run the latest version. Everything is open source and free.
