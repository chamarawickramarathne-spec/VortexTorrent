MEDIA SUPPORT - VORTEX TORRENT
================================

1. TITLE
Vortex Torrent

2. SHORT DESCRIPTION
A fast, free desktop BitTorrent downloader for Windows (32-bit and 64-bit) with a modern dark interface and a custom vortex logo. Add .torrent files or magnet links, pick exactly which files to download, control how many downloads run at once, track live progress, and keep your bandwidth in check - all in one clean, secure app that leaves zero clutter behind.

3. LONG DESCRIPTION
Vortex Torrent is a full-featured BitTorrent client for Windows - available for both 32-bit and 64-bit systems - built on the battle-tested libtorrent engine, wrapped in a sleek modern dark interface featuring a custom-designed vortex logo. It makes downloading legal, open content simple and fast. Add .torrent files or paste magnet links and Vortex handles the rest - discovering peers through DHT, peer exchange, and trackers so you get the fastest available speeds.

Smart file selection lets you choose exactly what you want before anything downloads. Add a .torrent and a checkbox dialog appears listing every file with its size - tick what you need, skip the rest. Add a magnet link and the same picker opens automatically the moment the torrent metadata arrives, pausing the download until you confirm your choice - Vortex downloads ONLY the files you select, nothing else. Your clipboard even does the work for you: open the Add Magnet dialog and any magnet link you copied is pasted in automatically.

New in version 1.10, an Active Downloads limit gives you full control over concurrency: set how many torrents may run at once (0 = unlimited) and Vortex queues the rest, automatically starting the next one the moment a slot frees up - no more bandwidth battles. The spotless-downloads engine from 1.9 is still here: the hidden internal part-files other clients leave scattered in your folders are cleaned up automatically the moment a torrent finishes, so your download directory contains exactly the files you picked, nothing more. Hybrid (v1+v2) torrents are handled correctly, so file selection works reliably on every modern torrent.

A beautiful, dark-themed interface shows every download as a live card with a progress bar, download speed, seed and peer counts, and estimated time remaining - flipping to a green "Completed" status the moment your selected files finish. Pause, resume, or remove torrents from the toolbar, a right-click menu, or handy keyboard shortcuts (Ctrl+O, Ctrl+M, Space, Delete). Double-click a finished download to open its folder instantly. Set your own download folder, speed limit, listening port, and active-download limit from a single settings dialog.

Built for download-only use, Vortex Torrent never uploads or seeds - it simply fetches what you ask for and then stops. Your privacy is respected: all configuration is stored locally. The built-in updater is hardened for safety: it only ever offers newer versions (never downgrades), verifies the installer's checksum and digital signature before running, and reuses a clean verified copy - so updates come from a trusted source every time. Everything is open source and free.
