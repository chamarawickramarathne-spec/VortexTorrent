Vortex Torrent

2. SHORT DESCRIPTION
A fast, free desktop BitTorrent downloader for Windows with a modern dark interface and a custom vortex logo. Add .torrent files or magnet links, pick exactly which files to download, track live progress, and control your bandwidth - all in one clean app.

3. LONG DESCRIPTION
Vortex Torrent is a full-featured BitTorrent client for Windows built on the battle-tested libtorrent engine, wrapped in a sleek modern dark interface featuring a custom-designed vortex logo. It makes downloading legal, open content simple and fast. Add .torrent files or paste magnet links and Vortex handles the rest - discovering peers through DHT, peer exchange, and trackers so you get the fastest available speeds.

Smart file selection lets you choose exactly what you want before anything downloads. Add a .torrent and a checkbox dialog appears listing every file with its size - tick what you need, skip the rest. Add a magnet link and the same picker opens automatically the moment the torrent metadata arrives, pausing the download until you confirm your choice - Vortex downloads ONLY the files you select, nothing else. Your clipboard even does the work for you: open the Add Magnet dialog and any magnet link you copied is pasted in automatically.

A beautiful, dark-themed interface shows every download as a live card with a progress bar, download speed, seed and peer counts, and estimated time remaining - flipping to a green "Completed" status the moment your selected files finish. Pause, resume, or remove torrents from the toolbar, a right-click menu, or handy keyboard shortcuts (Ctrl+O, Ctrl+M, Space, Delete). Double-click a finished download to open its folder instantly. Set your own download folder, speed limit, and listening port from a single settings dialog.

Built for download-only use, Vortex Torrent never uploads or seeds - it simply fetches what you ask for and then stops. Your privacy is respected: all configuration is stored locally and the app includes a built-in updater with a header button that checks GitHub for new releases, so you always run the latest version. Everything is open source and free.
